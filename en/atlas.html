list_dataset_resources Lists all files (resources) in a dataset with format, size, URL, and creation/modification dates.

List all resources (files) in a dataset with their metadata. Returns resource ID, title, format, size, download URL, and creation/ last-modified dates for each file. Download a resource's raw bytes from Ecuador's open data portal, base64-encoded. detect_series_pattern For datasets that publish one file per period: tells whether each new file replaces the previous ones (cumulative) or complements them (incremental).

When a dataset publishes one file per period (weekly/monthly), it's not always clear whether each new file replaces the previous ones (cumulative -- only the newest file matters) or complements them (incremental -- every file must be combined). Downloads the two most recent resources from the periodic-name group list_dataset_resources already detects, finds a date/period-like column by header name (fecha, mes, año, periodo, semana, ...), and compares which period values appear in both files. High overlap → cumulative; near-zero overlap → incremental; if no period column is found or the overlap is ambiguous, returns indeterminado rather than guessing. A heuristic over a sample of up to 500 rows per file -- confirm with preview_resource_data if the result is close to the threshold.

ParameterTypeDefaultDescription
dataset_idstrrequiredThe dataset ID or slug
resource_id_newstr | NonenoneOptional -- newer resource ID to compare (auto-detected from the dataset's periodic-name group if omitted)
resource_id_oldstr | NonenoneOptional -- older resource ID to compare (auto-detected if omitted). Both resource_id_new/resource_id_old must be given together, or neither.
sourcestrnacional"nacional" (default, www.datosabiertos.gob.ec) or "cuenca" (cuencaendatos.cuenca.gob.ec, independent municipal portal)
formatstrtextOutput format: `text` (default) or `json`.
search_sri_datasets Search across ~130 SRI files published outside the CKAN portal: RUC registry by province, tax collection, sales/purchases, vehicles, CEL, data dictionaries.

Search the SRI's open datasets page (sri.gob.ec/datasets) for direct file links. Returns direct URLs, not the file contents — download them yourself or via download_resource.

ParameterTypeDefaultDescription

formatstrtextOutput format: `text` (default) or `json`.

Government procedures4

search_tramites Search Ecuadorian government procedures (ID card, passport, RUC, driver's license, etc.).

Search for government procedures (trámites) on Ecuador's official portal gob.ec. Best approach: provide an institution_id to get that institution's trámites. Add a query to filter results by keyword (filters by name and description). When query is provided with institution_id, ALL pages of that institution's trámites are fetched and filtered, so you always get the most relevant results. Common institution IDs: - "8" = SRI (Servicio de Rentas Internas) — impuestos, RUC, facturación - "23" = Registro Civil — cédula, partidas de nacimiento - "62" = ANT — licencias de conducir, matriculación vehicular - "16" = Ministerio de Relaciones Exteriores — pasaportes, apostilla - "5" = IESS — seguro social, pensiones, fondos de reserva Use list_instituciones to find more institution IDs.

institution_idstremptyInstitution ID (strongly recommended for relevant results)
pageint1Page number (1-based, default: 1). Ignored when query is provided (all pages are searched automatically).
formatstrtextOutput format: `text` (default) or `json`.

ANDA (INEC)3

search_anda Search INEC's ANDA catalog of surveys and censuses (NADA/IHSN). Indicates whether each survey has downloadable microdata.

Search INEC's ANDA catalog (anda.inec.gob.ec) of surveys and censuses. ANDA runs on NADA (World Bank/IHSN), separate from datosabiertos.gob.ec. It catalogs 437+ INEC surveys/censuses with metadata (title, year, authoring entity). Not every entry has downloadable microdata — many are aggregate-only publications (e.g. price indices); each result says so. Follow up with get_anda_survey_info(idno) for full metadata on one survey.

formatstrtextOutput format: `text` (default) or `json`.
get_anda_survey_info Full metadata for an ANDA survey: summary, variables, confidentiality, and contact.

Get full metadata for one ANDA (INEC) survey/census by its idno. Get the idno from search_anda results — it's the string identifier (e.g. "IDD-ECU-INEC-CGTPE-DECON-ENESEM-2023-v1.3"), not the numeric id. Returns scope/abstract, variable count, whether microdata is actually downloadable, confidentiality terms, and a contact email for requesting restricted data when it isn't.

ParameterTypeDefaultDescription
idnostrrequiredSurvey identifier from search_anda (the "idno" field)
formatstrtextOutput format: `text` (default) or `json`.
download_anda_microdata Direct download links for an ANDA survey's microdata files.

Get direct download links for an ANDA survey's microdata files. Automates ANDA's one-click usage-terms step (research/statistical use only, no re-identifying respondents, cite the source — see get_anda_survey_info for the full text) to reveal the file list. Check get_anda_survey_info first: aggregate-only surveys (microdatos_disponibles false) have no files here. Returns direct URLs, not the file contents — the files are typically multi-MB ZIPs (SPSS .sav inside), too large to embed in a tool result. Download them with the returned URL.

ParameterTypeDefaultDescription

formatstrtextOutput format: `text` (default) or `json`.

Macroeconomics (BCE)2

search_indicadores_bce Search the Central Bank of Ecuador's statistical catalog (monetary/financial, public finance, external sector, real sector).

Search the Banco Central del Ecuador (BCE) statistical catalog. Covers monetary/financial statistics, public finances, external sector (foreign trade), and real sector (GDP, employment/ unemployment, consumer confidence, oil production, cement production, and more) — each result is an indicator group (id_grupo) whose time series data you fetch with get_indicador_bce. Some groups hold a single series, others dozens under a broader title (e.g. "desempleo" is a series inside the "mercado laboral" group, not a group of its own — matched here too, not just group titles). Does NOT cover Ecuador's own inflation (CPI) or poverty statistics — those are INEC's domain, try search_anda instead. First call after the cache expires (24h) takes ~10-15s: matching against series names, not just group titles, means fetching every group's metadata (~78 groups) once to build the search index. Cached after that.

limitint20Max results (default 20, max 100)
offsetint0Pagination offset over the matched set
formatstrtextOutput format: `text` (default) or `json`.

Time series data for one Banco Central del Ecuador (BCE) indicator group. Use search_indicadores_bce first to find the id_grupo. Frequency and unit vary by group (e.g. "Mensual"/"Millones de USD" for money supply, "Trimestral"/"Porcentaje" for GDP growth) — omit them to get the group's default, or check the error message for the valid options if you guess wrong.
