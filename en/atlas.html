detect_series_pattern For datasets that publish one file per period: tells whether each new file replaces the previous ones (cumulative) or complements them (incremental).

When a dataset publishes one file per period (weekly/monthly), it's not always clear whether each new file replaces the previous ones (cumulative -- only the newest file matters) or complements them (incremental -- every file must be combined). Downloads the two most recent resources from the periodic-name group list_dataset_resources already detects, finds a date/period-like column by header name (fecha, mes, año, periodo, semana, ...), and compares which period values appear in both files. High overlap → cumulative; near-zero overlap → incremental; if no period column is found or the overlap is ambiguous, returns indeterminado rather than guessing. A heuristic over a sample of up to 500 rows per file -- confirm with preview_resource_data if the result is close to the threshold.
