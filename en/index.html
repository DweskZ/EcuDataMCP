The problem

Less time in portals. More answers from your data.

Ecuador publishes a huge amount of public data, but finding it means navigating different portals, checking separate catalogs, and guessing which file is current. EcuDataMCP gives your AI assistant the tools to do that work for you, and still cites the official source in every answer.

How it works

A traceable path.

Four steps, from natural language to the official source.

01

Search

search_ecuador searches datasets, procedures, regulations, contracts, and risk events by keyword, all at once.

02

Inspect

get_dataset_info and list_dataset_resources check fields, formats, and dates before pulling any data.

03

Query

query_resource_data filters the CKAN DataStore without downloading the whole file, or preview_resource_data for CSV, JSON, and XLSX.

04

Cite

Every result links back to the official source (the dataset, the procedure, the SERCOP record) so you can verify it.

The backstage

Open-source MCP server.

EcuDataMCP runs as a FastMCP server in Python, exposed over Streamable HTTP or stdio. There is no database of its own: every tool calls the matching official portal live (CKAN, gob.ec, SERCOP, BCE, Supercías, IG-EPN, SGR) and returns the formatted response.

FAQ

Got more questions?

What is EcuDataMCP?

An open-source MCP (Model Context Protocol) server that helps your AI assistant discover and query Ecuador's open government data: datasets, procedures, regulations, public contracts, risk events, earthquakes, Central Bank indicators, and companies.

What is MCP?

Model Context Protocol is an open standard for connecting AI assistants to external tools and data sources, while keeping control over what the model can do and what data it can read.

What assistants can I use?

Any MCP-compatible client: Claude Desktop, Claude Code, ChatGPT (paid plans), Cursor, VS Code, Gemini CLI, Le Chat, Windsurf, HuggingChat, and more.

Do I need an API key?

No. Every source the server uses is public data with no authentication.

Is this an official service of the Ecuadorian government?

No. EcuDataMCP is an independent, open-source project that queries the same public sources the Ecuadorian state already publishes. It is not affiliated with any institution.

Does the server store my questions?

There is no telemetry. The server runs locally on your machine, and every query goes straight from the MCP client to the matching official portal.

What formats does it support?

In-memory preview of CSV, TSV, JSON, GeoJSON, and XLSX; filtered tabular queries via the CKAN DataStore when the resource supports it.

Why does the connection to the Open Data portal sometimes fail?

www.datosabiertos.gob.ec sometimes rejects connections coming from outside Latin America (403 error). If you see this, run the server from a connection with an exit point in Ecuador or the region (a VPN, for example). The procedures and institutions tools use a different portal and don't have this issue.

Can I contribute?

Yes, the project is MIT-licensed and accepts pull requests. See the guide at Contribute.
