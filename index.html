Infraestructura abierta de datos públicos para Ecuador

Explora datos abiertos.

Aviso: Algunas definiciones, parámetros y descripciones de herramientas fueron generados o asistidos por IA. Pueden estar incompletos o desactualizados; una herramienta puede devolver resultados parciales, rechazar parámetros válidos o comportarse inesperadamente cuando cambia la fuente oficial. Verifica siempre la respuesta contra la fuente enlazada y revisa manualmente los resultados antes de usarlos para decisiones importantes.

El problema

Menos tiempo en portales. Más respuestas de tus datos.

Ecuador publica una enorme cantidad de datos públicos, pero encontrarlos significa navegar portales distintos, revisar catálogos separados y adivinar cuál archivo está vigente. EcuDataMCP le da a tu asistente de IA las herramientas para hacer ese trabajo por ti, y sigue citando la fuente oficial en cada respuesta.

Cómo funciona

Un camino trazable.

Cuatro pasos, del lenguaje natural a la fuente oficial.

01

Buscar

search_ecuador busca a la vez en datasets, trámites, regulaciones, contratos y riesgos por palabra clave.

02

Inspeccionar

get_dataset_info y list_dataset_resources revisan campos, formatos y fechas antes de traer datos.

03

Consultar

query_resource_data filtra en el DataStore de CKAN sin descargar el archivo completo, o preview_resource_data para CSV, JSON y XLSX.

04

Citar

Cada resultado enlaza a la fuente oficial (el dataset, el trámite, el expediente SERCOP) para que puedas verificarlo.

El backstage

Servidor MCP de código abierto.

EcuDataMCP corre como un servidor FastMCP en Python, expuesto sobre HTTP Streamable o stdio. No hay base de datos propia: cada tool llama en vivo al portal oficial correspondiente (CKAN, gob.ec, SERCOP, BCE, Supercías, IG-EPN, SGR) y devuelve la respuesta formateada.

Si tu asistente tiene acceso a una terminal, pégale el link del repositorio y déjalo instalar todo por ti:

y regístralo como servidor MCP en mi cliente usando modo stdio con

FAQ

¿Tienes más preguntas?

¿Qué es EcuDataMCP?

Un servidor MCP (Model Context Protocol) de código abierto que ayuda a tu asistente de IA a descubrir y consultar datos abiertos del gobierno de Ecuador: datasets, trámites, regulaciones, contratos públicos, riesgos, sismos, indicadores del Banco Central y compañías.

¿Qué es MCP?

Model Context Protocol es un estándar abierto para conectar asistentes de IA con herramientas y fuentes de datos externas, manteniendo el control sobre qué puede hacer el modelo y qué datos puede leer.

¿Qué asistentes puedo usar?

Cualquier cliente compatible con MCP: Claude Desktop, Claude Code, ChatGPT (planes pagos), Cursor, VS Code, Gemini CLI, Le Chat, Windsurf, HuggingChat, y más.

¿Necesito una API key?

No. Todas las fuentes que usa el servidor son datos públicos sin autenticación.

¿Es esto un servicio oficial del gobierno ecuatoriano?

No. EcuDataMCP es un proyecto independiente de código abierto que consulta las mismas fuentes públicas que ya publica el Estado ecuatoriano. No está afiliado a ninguna institución.

¿El servidor guarda mis preguntas?

No hay telemetría. El servidor corre localmente en tu máquina y cada consulta va directo del cliente MCP al portal oficial correspondiente.

¿Qué formatos soporta?

Preview en memoria de CSV, TSV, JSON, GeoJSON y XLSX; consulta tabular filtrada vía el DataStore de CKAN cuando el recurso lo soporta.

¿Por qué a veces falla la conexión al portal de Datos Abiertos?

www.datosabiertos.gob.ec a veces rechaza conexiones que vienen de fuera de Latinoamérica (error 403). Si ves esto, corre el servidor desde una conexión con salida en Ecuador o la región (por ejemplo, una VPN). Los tools de trámites e instituciones usan otro portal y no tienen este problema.

¿Puedo contribuir?

Sí, el proyecto es MIT y acepta pull requests. Ve la guía en Cómo colaborar.
