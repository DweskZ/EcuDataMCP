Cómo colaborar

Suma tu fuente, tu tool, tu idea.

EcuDataMCP es MIT y acepta pull requests. No hace falta ser experto en MCP ni en el stack completo del proyecto: la mayoría de contribuciones tocan una sola pieza.

Flujo de contribución

Fork, branch, PR.

01

Fork

Haz fork de DweskZ/EcuDataMCP a tu cuenta.

02

Branch

git checkout -b feature/nueva-herramienta

03

Commit

git commit -m 'feat: agregar nueva herramienta'

04

Pull Request

Push a tu fork y abre un PR describiendo el cambio.

Servidor MCP

Python, uv, pytest.

El servidor vive en tools/, helpers/, resources/ y prompts/. Requiere Python 3.11+ y uv.

uv sync
uv run pytest
uv run ruff check .

Un tool nuevo normalmente son tres archivos: la función en tools/, su registro en tools/__init__.py, y un test en tests/.

Cada fuente que falta, cada tool que le falta cobertura, es una contribución posible.
