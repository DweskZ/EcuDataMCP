About

A bridge between public data and your AI assistant.

EcuDataMCP exists because finding a public data point in Ecuador almost always means guessing which portal it's on, under what name, and in what format. The server gives your assistant the tools to do that search for you, and always lets you verify against the official source.

History

Where it comes from.

EcuDataMCP started as DweskZ/EcuDataMCP. Since then, DweskZ and Daniel Sánchez Pazmiño have maintained it together: new sources (SRI Datasets, BCE, Supercías auditors), more robust error and download handling, and this site, so connecting the server doesn't depend on reading a README end to end.

Independence

Not a service of the Ecuadorian state.

EcuDataMCP is an independent, open-source project. It queries the same public sources that Ecuadorian government institutions already publish (CKAN, gob.ec, SERCOP, BCE, Supercías, IG-EPN, SGR), but it is not affiliated with, funded by, or endorsed by any of them. Every answer links to the official source precisely so that distinction stays clear: what you see is what the portal publishes, not a copy.

License & maintenance

MIT, and open for you to use.

The full codebase (MCP server and this site) is MIT. It's maintained by DweskZ and Daniel Sánchez Pazmiño. Want to add a source, a tool, or fix something? Start at Contribute.
